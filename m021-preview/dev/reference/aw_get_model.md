# Get a Whisper model from a local or online source

This function is an alias for `audio.whisper::whisper()`. Refer to
`audio.whisper::whisper()` for full documentation of available
parameters and usage details.

## Usage

``` r
aw_get_model(...)
```

## Arguments

- ...:

  Arguments passed on to `audio.whisper::whisper()`; see that function's
  documentation for the available parameters.

## Value

The result from `audio.whisper::whisper()`.

`audio.whisper::whisper()`
